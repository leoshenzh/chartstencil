# ChartStencil plan

- Goal: independent chart templates and rendering tools with no bundled business content.
- Scope: 119 chart types, 73 source modules, chart runtime, five palettes, light/dark modes, SVG export, input contracts, Python builder and D3 notices.
- Excluded: geographic maps, datasets, demonstration narratives, preset titles/conclusions, promotional images, report/PPT workflows and private integrations.
- Verification: 476 render checks and 60 SVG appearance checks passed; details in RELEASE.md.
- Release: v0.1.0. Source-only distribution; caller data and generated files stay outside this repository.
