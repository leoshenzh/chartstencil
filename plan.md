# ChartStencil plan

- Goal: independent chart templates and rendering tools with no bundled business content.
- Scope: 119 chart types, 73 source modules, chart runtime, five palettes, light/dark modes, SVG export, input contracts, Python builder and D3 notices.
- Excluded from the tool: geographic maps, datasets, demonstration narratives, preset titles/conclusions, report/PPT workflows and private integrations.
- Verification: 476 render checks and 60 SVG appearance checks passed; details in RELEASE.md.
- Release: v0.1.0. The published tool-only ZIP remains unchanged.
- Documentation: English and Chinese READMEs, six synthetic chart previews in each language, and five-palette/light-dark overview images. Documentation images live in docs/images; no raw demonstration datasets are distributed.
- README delivery: verify local links, visual rendering, image metadata, and the public GitHub display.
