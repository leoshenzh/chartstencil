# Documentation images

These images were rendered with ChartStencil using neutral, synthetic inputs. All names and values are fictional. They are documentation illustrations, not raw datasets or real business records.

The six chart types are Sankey, rank ribbons, nested Voronoi, Marimekko, unit flow, and bubble matrix. Each has English and Chinese presentation variants. The palette overview shows the same Sankey data in five palettes and two themes; labels are omitted in these small palette thumbnails for legibility.

Chart geometry comes from the included renderer. Documentation presentation adds a project heading, chart description, and synthetic-data footer. PNG files contain no embedded author, location, or source-path metadata.

These documentation assets are covered by the repository MIT license. They are not part of the tool-only v0.1.0 release ZIP.
